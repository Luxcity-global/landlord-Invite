## Operating Protocols for Agents

1. **Brand Conformity:** Check `context/PRODUCT_OVERVIEW.md` before generating copy, UI, or templates.
2. **Constraint Enforcement:** Never insert unverified quantitative claims (especially `41%` and `£2,700`).
3. **Atomic Ownership:** One agent per task. Do not edit another agent's assigned output file without recording notes.
4. **Handoff Quality:** Every artifact must be self-contained, documented, and immediately reviewable by human stakeholders.
